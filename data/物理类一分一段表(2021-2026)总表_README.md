# 广东物理类志愿填报数据补充包（2026-09-19）

本次在已有"院校专业组投档分"基础上，补齐两块硬数据：

## 一、物理类一分一段表（2021-2026）
位置：`yifenyiduan/csv/`
- `guangdong_wuli_yifenyiduan.csv` 合并总表
- `by_year/gd_yfd_YYYY.csv` 分年

字段：`年份, 分数, 本段人数, 累计人数(=全省位次)`

用途：考生输入分数 → 查表得到"累计人数"即全省位次 → 用位次比对历年院校专业组投档位次。
验证：各年本科线累计人数与官方新闻完全吻合（2021本科432→222304人；2026本科425→303919人）。

## 二、院校专业选科要求（2024-2026年版，物理首选）
位置：`xuanke/xuanke_requirements.csv`（约8.4万条）

字段：`地区, 院校代码, 院校名称, 层次, 专业(类)名称, 首选科目要求, 再选科目要求, 包含具体专业`

来源：广东省教育考试院《2024-2026年拟在粤招生普通高校本专科专业选考科目要求（3+1+2）》查询系统，全量抓取2085所院校。

关键筛选项：
- 首选科目要求：`仅物理` / `物理或历史均可`
- 再选科目要求：`不提科目要求` / `化学(必选)` / `化学,生物(均须)` 等

用途：筛选出"物理类考生（按自己再选科目）能报的专业类"，过滤掉选科不符的专业组。
注：2027年起执行新版选科要求，网址 https://www.eeagd.edu.cn/xkcx2027/ ，届时需重新抓取。
